# 0001. Record architecture decisions

## Context and problem statement

DevBox makes many opinionated choices on behalf of every project that adopts it. Contributors (human and agent)
need to know which choices were deliberate before changing them.

## Decision outcome

We will keep MADR 4 style ADRs in `docs/adr/`, numbered sequentially, created with `bin/devbox adr "<title>"`.
Accepted ADRs are superseded, never edited.
